# game_configs/

Live game resource configurations.

- **77 JSON files**, one per game ID (`gXXXX.json`)
- Each file is keyed by engine version and describes the maps, configuration files, hashes,
  and download URLs published for that version.
- **72** of these games have archived files under `games/`.
- The remaining five (`g2005`, `g2036`, `g2038`, `g2049`, `g2066`) are live configs without
  an archived game folder in this snapshot.

See [../reports/GAME_INVENTORY.md](../reports/GAME_INVENTORY.md) for names, version ranges,
map counts, and sizes across all 77 live games.
